# Paper figures and tables

Everything in this folder is generated by `experiments/make_paper_figures.py` from the tracked aggregate
records `research/main_results_test.json`, `main_results_extensions.json` and `main_results_dfdm.json`.
No raw predictions, crops or models are needed. Before drawing, the script recomputes the FF++ and DFDM
primary contrasts from the curves and checks them against the stored registered values.

Regenerate (from the repository root):

```powershell
& .\DeepFake\Scripts\python.exe experiments/make_paper_figures.py --render --force
```

Without `--force` the script refuses to overwrite existing files. `--render` uses a headless Edge or
Chrome to turn each SVG into a vector PDF and a 3× PNG; without it only the SVGs and tables are written.

## Figures (`figures/`)

Use the PDFs in LaTeX (`\includegraphics{figures/fig1_retention.pdf}`); the PNGs are for slides and
previews. Draft captions, including which values are registered and which are post-freeze extensions,
are in [figures/captions.md](figures/captions.md).

| File | Width | Content |
|---|---|---|
| `fig1_retention` | two columns | Headline: detection vs attribution retention under JPEG, FF++ vs DFDM, at the frozen threshold and threshold-free |
| `fig2_granularity` | one column | Retention by attribution granularity (FF++ family / pairwise / four-way, DFDM five-way) at Q60 and Q20 |
| `fig3_confusion` | two columns | Attribution confusion at Ref and Q20, FF++ and DFDM |
| `fig4_delta_auc` | one column | Forest plot of Δ_AUC(Q20) across models, probes and datasets |
| `fig5_e10` | one column | External Celeb-DF detection AUROC under JPEG |

## Tables (`tables/`)

Each `.tex` file is a complete `table`/`table*` environment with caption and label; it needs
`\usepackage{booktabs}`. `tables.md` holds the same tables in Markdown for drafting.

| File | Label | Content |
|---|---|---|
| `tab1_datasets` | `tab:datasets` | Test sets, class counts and bootstrap groups |
| `tab2_ffpp_curves` | `tab:ffpp-curves` | FF++ BA curves, mean ± SD |
| `tab3_ffpp_primary` | `tab:ffpp-primary` | FF++ primary contrast P1 per seed, with Δ_AUC and EfficientNet-B4 |
| `tab4_dfdm_curves` | `tab:dfdm-curves` | DFDM BA and AUROC curves, including whole-video CRF |
| `tab5_dfdm_primary` | `tab:dfdm-primary` | DFDM primary contrast D-P1 per seed |
| `tab6_controls` | `tab:controls` | Shortcut controls on both datasets |
| `tab7_augmentation` | `tab:augmentation` | JPEG augmentation minus reference training |
| `tab8_e10` | `tab:e10` | External Celeb-DF test E10 |
| `tab9_codec` | `tab:codec` | FF++ whole-video H.264/H.265 re-encoding (X5) |
| `tab10_encoders` | `tab:encoders` | Frozen pretrained encoders: DINOv2, CLIP (X7) and I-JEPA (X8) |

Values marked † or ‡ are post-freeze extensions; say so wherever they are cited.
